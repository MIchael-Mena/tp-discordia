Administrar la configuración del servidor (HU-39)

Personalización de nombre, ícono y banner con subida directa a Amazon S3 y actualización en vivo.

Edición de nombre, ícono y banner

El servidor dejó de tener solo el nombre inicial: ahora se puede personalizar su identidad visual o quitar las imágenes cuando se desee.

Subida directa a Amazon S3

El backend valida permisos y firma una autorización temporal para que la aplicación suba la imagen directo a S3 sin saturar el servidor.

Limpieza de S3 y sincronización en vivo

Al guardar una nueva imagen, el servidor borra automáticamente la imagen vieja en S3 y avisa en vivo a todos los miembros conectados.

Reglas relevantes para la demo

Solo el Owner o miembros con rol ADMINISTRATOR pueden editar estos ajustes. Se validan imágenes JPG, PNG o WEBP de hasta 5 MB.
