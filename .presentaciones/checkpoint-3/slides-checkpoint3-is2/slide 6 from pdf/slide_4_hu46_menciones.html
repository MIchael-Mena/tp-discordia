CHECKPOINT 3  ·  04.3  ·  HISTORIA DE USUARIO HU-46

Menciones (HU-46)

Mencionar usuarios, roles o a todos para generar notificaciones dirigidas.

Tres tipos de mención

Se escriben como <@usuario>, <@&rol> y @everyone; el servidor las extrae a una estructura mentions que se guarda y se difunde.

Permisos y roles mencionables

Mencionar a todos o a un rol exige permiso; un rol además debe estar marcado como mencionable. Sin eso el texto se conserva sin generar alerta.

Notificación destacada

notifications crea una alerta de alta prioridad con bandeja persistente; el autor nunca recibe la suya.

Reglas relevantes

Una mención sin permiso no se rechaza: el mensaje se envía como texto plano. Si un miembro es alcanzado por varias menciones, recibe una sola notificación.
